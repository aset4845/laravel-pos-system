# Laravel POS System

Система учёта продаж (Point of Sale) на базе **Laravel**, с готовыми модулями продаж, закупок, отчётов и встроенной мультиязычностью, включая казахский язык.

## Возможности

- Продажи и учёт товаров, закупки, склад
- Отчёты и экспорт в PDF (dompdf)
- Управление пользователями и правами доступа
- Встроенная мультиязычность интерфейса: English, Русский (через пакет) , казахский (`kk`, `kz`), арабский, китайский, французский, немецкий (`gr`), испанский, турецкий, вьетнамский

## Технологии

- PHP 8.1, Laravel 10
- AdminLTE-шаблоны (infyomlabs), Laravel Generator
- MySQL
- Laravel Sanctum, Guzzle, Laravel Dompdf

## Установка (XAMPP / локально)

1. Скопируйте папку проекта в `C:\xampp\htdocs\` (или в отдельную директорию, если используете встроенный сервер Laravel).
2. Запустите **MySQL** (в XAMPP Control Panel или локально).
3. Создайте базу данных `pos` и импортируйте дамп `pos.sql` через phpMyAdmin — либо выполните миграции Laravel.
4. Скопируйте `.env.example` в `.env` и настройте подключение к БД (`DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`).
5. Установите зависимости и сгенерируйте ключ приложения:
   ```bash
   composer install
   php artisan key:generate
   php artisan storage:link
   ```
6. Запустите сервер:
   ```bash
   php artisan serve
   ```

> ⚠️ Файл `.env` с реальными настройками не публикуется в репозитории — используйте `.env.example` как шаблон. Папка `vendor/` не включена, выполните `composer install` после клонирования.
